# Pobreza-de-tiempo-en-la-Ciudad-de-M-xico-2019-2024
En este repositorio se encuentra el código para la construcción de las bases de datos de los indicadores publicados por el INEGI a través de la Encuesta Nacional de Uso de Tiempo 2019 y 2024, así como la construcción de diversos modelos econométricos.
Las bases de datos pueden consultarse en la siguiente dirección:
https://www.inegi.org.mx/programas/enut/2024/
